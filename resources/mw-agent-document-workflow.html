Medical Writing × Agentic AI

從零開始一份文件：
MW 如何啟動 Agent 工作流

把 AI 放在正確的位置：先盤點證據，再規劃、起草、核查，最後由 MW 做決策。

HiRO Edge｜繁體中文工作指南

本簡報聚焦於文件工作的第一步：如何讓 Agent 從「理解任務」開始，而不是直接生成全文。

01 / 核心觀念

不要從「寫全文」開始

01

先建立上下文

文件目的、研究階段、地區、模板、截止日期。

02

先鎖定證據

每個重要結論都要能追溯到來源與位置。

03

再分章節起草

以章節為單位，逐步生成、逐步確認。

04

最後做品質控制

數據、邏輯、術語與跨文件一致性分開檢查。

關鍵轉變：讓 Agent 先當「工作分析員」，再當「起草助手」。

02 / 啟動前

先準備一個文件任務包

類別需要提供Agent 的用途
文件定位CSR / Protocol / IB / CTD選擇結構與工作流
研究背景階段、適應症、治療方案建立寫作上下文
來源資料Protocol、SAP、TFL、Narratives建立證據鏈
交付要求模板、語言、格式、期限定義完成標準

資料不足時，先列出缺口；不要讓 AI 以推測填補。

03 / Intake

第一個 Agent 任務：資料盤點

SOURCE

建立來源文件清單，標記版本、日期、狀態。

DATA LOCK

區分已確認、待確認、不可使用的資料。

GAP LOG

列出缺失資料及其對章節與時程的影響。

輸出不是正文。

輸出是一張可供 MW 審閱的「工作地圖」，讓後續起草有邊界、有來源。
建議把 Source Manifest、Data Lock Table、Claim-Evidence Matrix 與 Gap and Impact Log 作為固定啟動產物。

04 / Planning

第二個 Agent 任務：文件規劃

文件要求模板、法規、Sponsor 偏好
→
章節地圖每章目的與必要輸入
→
證據分配來源對應到段落與表格
→
風險排序先處理高影響缺口
MW 的審閱重點：Agent 的大綱是否符合文件目的，而不只是看起來完整。

05 / Evidence

讓每個重要結論都有證據

Claim｜主張

治療在目標族群中顯示出臨床活性。

Evidence｜證據

CSR Section 11.4；Table 14.2.1；資料截止日。

Interpretation｜解讀

由 MW / SME 判斷臨床意義與限制。

Status｜狀態

已確認／待確認／不可使用

AI 可以整理證據與差距；不能替代醫學判斷。

06 / Drafting

第三個 Agent 任務：分章節起草

輸入資料表格、圖、Listing、Narrative
→
生成敘述依模板與監管語氣組織
→
標注來源保留表號、章節、頁碼
→
標記缺口[待確認：XXX]
建議：先從一個高重複、邊界清楚的章節試行，例如 CSR 的研究結果或安全性摘要。

07 / Quality Control

把起草與 QC 分成兩個角色

起草 Agent

  • 整理內容
  • 建立敘事
  • 保留來源
  • 標記缺口

QC Agent

  • 查數字與日期
  • 查分析集與終點
  • 查術語與縮寫
  • 查跨文件矛盾

同一個 Agent 既寫又判定自己正確，容易漏掉問題。

08 / Cross-check

最值得自動化：跨文件一致性

Protocol ↔ ICF

入排標準、風險、受試者流程

IB ↔ CSR

劑量、安全性、臨床資料

IB ↔ RMP

已識別風險、潛在風險

輸出格式：文件 A 位置 → 文件 B 位置 → 差異類型 → 建議統一表述。

09 / Prompt

可直接複製的啟動指令

你是本文件的 Medical Writing Agent。
文件類型：[CSR / Protocol / IB / CTD]
文件目的：[提交 / 更新 / 回覆審評意見]
適用地區：[FDA / NMPA / EMA]

請先不要起草正文，先輸出：
1. Source Manifest
2. Data Lock Table
3. Claim-Evidence Matrix
4. Gap and Impact Log
5. 文件大綱與工作順序

不得捏造數據。資料不足時標記 [待確認：XXX]。
每個重要主張都必須附來源位置。

10 / Operating Model

最終責任仍在 MW

Agent 負責

盤點、整理、起草、比對、標記風險、產生修改建議。

MW 負責

證據取捨、醫學解讀、利益-風險立場、最終定稿。

最小可行工作流： Intake → Plan → Draft → Audit → Cross-check → Refine
這套流程的重點是把可重複工作交給 Agent，把需要專業判斷的工作保留給 MW、SME 和統計師。
Start small. Verify every claim.

先選一個章節，
今天就開始。

建議從 CSR 結果或安全性摘要開始，建立第一個可重複的 Agent 工作流。
