Welcome to the Sponsor Material Intake SOP briefing. We will walk through the 10-step closed-loop process to ensure data integrity and compliance in regulatory medical writing.

Golden Rule: Lock Before Write

Best Practice: Lock & Verify

Establish logs, stratify data, and construct a lock table to secure facts and clarify data gaps before outlining the document structure.

✓ Guarantees source traceability and minimizes rework caused by mid-process data shifts.

High Risk: Immediate Drafting

Drafting content immediately after reading files. This frequently leads to:

  • Mixing expired and current data sets
  • Overlooking underlying data logic conflicts
  • Making blind "inferences" when key facts are missing
"Lock before write" is our operational foundation. Most document rewrites occur because writers pull unverified numbers from email chains or chats.

1. Identify Project Boundary

Before reading, anchor the scope of work and jurisdictional parameters:

  • Project Details: Confirm drug code, target indication (e.g., solid tumor), and current phase.
  • Document Type: Identify target deliverables, such as Protocol, Investigator's Brochure (IB), Clinical Study Report (CSR), or Informed Consent Form (ICF).
  • Regulatory Jurisdiction: Determine the target health authority (NMPA, FDA, EMA, TGA) to lock template specifications.
  • Mark Data Gaps: Clearly flag any missing parameters using standard placeholders:
    [TBD: Target Section]      [TBD: Data Cut-off Date]
First, we must clarify target health authorities. If key info is missing, use the standard [TBD] brackets as placeholders.

2. Build Source Manifest

Catalog all incoming sponsor documents to prevent version confusion and ensure tracking:

ID File Name Doc Type Version / Date Coverage Loc / Page Status
SRC01 Protocol_v2.0_2026-06-07.pdf Protocol v2.0 (2026-06-07) I/E Criteria, Endpoints Sec 4, Page 12 Locked
SRC02 Safety_Data_Table_C3_v1.xlsx Safety Table v1.0 (2026-07-01) AE/SAE Summary Sheet: Sum, B5:F20 Locked
SRC03 Draft_IB_v0.5_CN.docx Draft IB v0.5 (2026-05-15) Nonclinical PK Sec 5.2, Page 45 TBD
Requirement: Proactively identify and flag duplicate files, superseded versions, and conflicting file versions.
The Source Manifest catalogs all inputs. Always specify exact locations—down to sheet tab and cell range for spreadsheets.

3. Data Stratification

Classify all regulatory statements to maintain rigorous evidence standards:

1. Sponsor-Confirmed
Definition: Clinical data, study designs, or statistical findings explicitly provided and signed off by the sponsor.

Action: Cited as Core Facts. Every reference must map to a Source ID.
2. External Evidence
Definition: Peer-reviewed literature, official guidelines, competitor clinical trial registration, or drug databases.

Action: Used as Background Support. Requires full citation/bibliographic source tracking.
3. Inference
Definition: Calculations, projections, or clinical assertions proposed by medical writers or AI agents based on incomplete data.

Action: Do not write as fact. Frame as advice and flag with `[TBD]` for sponsor approval.
This stratification ensures that assumptions do not bleed into clinical facts. Logical inferences must always be approved by the sponsor.

4. Establish Data Lock Table

Prior to drafting, secure a hard lock on key clinical variables:

  • Design Parameters: Sample size, dose cohorts, and dosing schedule (regimen).
  • Trial Logic: Primary efficacy endpoints, key inclusion/exclusion criteria.
  • Safety & PK: Severe adverse events (SAEs), dose-limiting toxicities (DLTs), critical PK/PD constants.
  • Temporal Factors: Data Cut-off Date, protocol version numbers, and corresponding dates.
Lock Example:

Dose Level10 mg/kgSRC01, Sec 5.3, p40
Primary EPORR (RECIST 1.1)SRC01, Sec 3.2, p24
A locked table serves as the single source of truth for the entire writing project. Every key number should reference this table.

5. Document Gaps & Conflicts

When data contradictions arise, do not make arbitrary writing decisions. Maintain a Gap Log:

Conflict/Gap Description Risk Level Impacted Sections Required Sponsor Action Status
Protocol claims PFS as primary endpoint; SAP lists ORR. High Protocol Sec 3.0 / CSR Sec 9.0 Clarify primary endpoint and provide final SAP decision. Open
Cycle 3 safety summary missing; only C1 & C2 available. Medium CSR Sec 12.0 / IB Sec 6.2 Provide missing Cycle 3 safety aggregate dataset. Open
References site an outdated 2020 FDA guideline version. Low Protocol References Update references to the current June 2026 guidelines. Open
Never try to reconcile documents silently. If the Protocol and the SAP clash, log it immediately and route it back to the sponsor for sign-off.

6. External Evidence Search

Conduct targeted external searches to support study rationale or resolve data gaps:

Search Scope & Registers

  • Trial Design Precedents: Search registries (e.g., ClinicalTrials.gov) to review cohort sizes, endpoints, and dosing for comparator trials.
  • Regulatory Precedents: Pull target-specific guidance papers from FDA, EMA, or NMPA (CDE).
  • Safety & Clinical Literature: Identify safety profiles (e.g., CRS, neurotoxicity) for matching drug classes.

Traceability Requirements:

All external references must capture the following metadata:

  • Exact search database and key terms used
  • Version or release date of reference materials
  • Unique identifiers (DOI / PMID / NCT number)
  • Date of access by the medical writing team
External search results are highly valuable for justifying dose selections. Keep audit trails for all external datasets.

8. Structured Drafting

Use standard regulatory templates and adhere strictly to scientific writing standards:

Objective & Neutral Voice
Use third-person, passive, or objective voice. Avoid first-person pronouns like "we" or "I" and subjective superlatives.
Avoid colloquialisms: e.g., instead of "the drug was highly safe," write "the investigational product was well tolerated, with no DLTs observed."
Precision & Terminology
Define all technical terms on first use (e.g., RECIST 1.1, CTCAE v5.0). Maintain consistency across sections.
Do not overstate clinical findings: never report nonclinical or early exploratory indicators as confirmed generalizable facts.
Our voice must remain analytical. Always use objective terms like "tolerable" rather than commercial terms like "highly safe".

10. Pre-delivery Tri-dimensional QC

Prior to external delivery, execute the final tri-dimensional verification workflow:

1. Citation QC
Verify every bibliographic citation.

Cross-check DOI, PMID, and NCT entries to ensure literature statements match the original published research.
2. Intra-Document QC
Audit internal consistency.

Confirm that statistical descriptors in the methodology sections align with summary data tables and footnotes.
3. Cross-Check
Perform inter-document sanity checks.

Verify terminology alignment between Protocol, Investigator's Brochure, and ICF to catch discrepancies.
Tri-dimensional QC is our final line of defense. It captures numeric slip-ups and mismatched terminology before documents reach the client.

Four Core Integrity Questions

Verify every statement and data point against these four questions:

  1. What is the source? (Verify precise input file)
  2. What is the version? (Confirm version and date)
  3. Where is the location? (Trace exact page or sheet coordinate)
  4. Is it confirmed? (Has the sponsor signed off, or is it an inference?)
Use this intake template for project kick-off. Always challenge key facts with the four integrity questions before final sign-off.
